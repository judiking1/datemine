# datemine — Product Spec (v0)

## 한 줄 정의
매일 아침 30초, "오늘이 무슨 날이고 어떤 발언·행동이 지뢰인지"를 확인하는
경각심 캘린더 앱. 운세 앱 포맷 + 사회적 리스크 브리핑.

## 타겟
- 인플루언서·유튜버·마케터·홍보/커뮤니케이션 담당
- SNS 발언 리스크를 신경 쓰는 일반 사용자

## 핵심 가치
- 매일 다른 콘텐츠(습관화) + 직설적·실용적 경고(경각심)
- "매년 반복되는 실패 패턴"을 미리 알려주는 지뢰밭 지도

## 톤 정책 (제품 정체성)
- 직설적·자극적 카피 허용: "오늘은 ○○ 발언 조심하세요"
- 단, 아래 **법적 가드레일**은 절대 위반 금지.

## 법적 가드레일 (하드 규칙 — 위반 시 서비스 불가)
1. 특정 개인의 실명 + "욕먹음/논란" 조합을 저장·표시하지 않는다.
   → "누가"가 아니라 "무엇이 문제였나(유형·패턴)"만 저장한다.
2. 뉴스 검색은 패턴 추출용 재료로만 쓰고, 결과물엔 개인 식별정보를 남기지 않는다.
3. 모든 패턴 카드는 게시 전 **사람 검수 게이트**를 통과한다(개인명·낙인 표현 제거).
4. 역사·기념일 사실은 공적 사료 기반으로만 기술한다.

## 데이터 모델
```
DailyContext {
  date, lunar/solar,
  dayType: 공휴일 | 기념일 | 추모일 | 선거 | 평일,
  significance: 이 날의 의미(교육적),
  riskPatterns: [{ pattern, whyItBackfires, exampleSummary(익명화), severity }],
  advice: 오늘의 자제 카피
}
```
- 백본 A(고정): 한국 달력 전체 날짜 × 의미. 1회 구축 후 매년 재사용.
- 백본 B(패턴): 뉴스 검색 → 유형화 → 검수 → 축적. 개인명 대신 유형.

## 기술 스택 (근본·안정·유지보수)
- 모노레포: pnpm workspaces + Turborepo, TypeScript 전면
- 앱: React Native + TypeScript (단일 코드베이스)
- 백엔드: Node + Hono(또는 NestJS), PostgreSQL, Drizzle/Prisma
- 공유 도메인 패키지: 앱·백엔드가 같은 타입 공유
- 콘텐츠 파이프라인: 검색 → LLM 유형화 → 사람 검수 → DB 커밋
- 아키텍처 원칙: 데이터 = source of truth, UI/알림은 파생 consumer

## MVP 스코프 (1차)
1. 한국 공휴일·기념일·추모일 12~20개 패턴 카드 큐레이션
2. 오늘 날짜 매칭 → 카드 노출(없으면 "평범한 날" 카드)
3. 아침 푸시 알림
4. 카드 공유(바이럴 훅)

## 로드맵
- P0: 모노레포 뼈대 + 백본 A 스키마
- P1: 앱 MVP(오늘 카드) + 알림
- P2: 백본 B 파이프라인(검수 게이트 포함)
- P3: 음력·지역 이벤트 확장, 개인화
